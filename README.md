## 👨‍💻 About Me

I am a passionate **DevOps & Cloud Infrastructure Engineer** dedicated to building resilient, scalable, and automated cloud-native platforms. My work centers on eliminating manual toil, automating deployment lifecycles, and embedding security (DevSecOps) from commit to cluster.

- 🔭 **Current Focus:** Modular Infrastructure as Code (Terraform), Kubernetes Platform Engineering (EKS/K8s), and GitOps pipelines (ArgoCD & GitHub Actions).
- ⚙️ **Philosophy:** Everything as Code (IaC, CaC, PaC), zero-downtime progressive rollouts, and proactive observability.
- 💬 **Ask me about:** AWS, Docker, Kubernetes, Terraform, Helm, CI/CD, GitOps, Monitoring with Prometheus/Grafana, and Linux automation.

## 🏗️ DevOps Lifecycle & Architecture Workflow

```
       [ Developer Commit ]
               │
               ▼
      [ GitHub Actions CI ] ──► (Linting, Unit Tests, Static Code Analysis)
               │
               ▼
   [ Container Security (Trivy) ]
               │
               ▼
   [ Build & Push Image (GHCR/ECR) ]
               │
               ▼
   [ GitOps Repo Update ] ──► (Helm Chart / K8s Manifest Version Bump)
               │
               ▼
         [ ArgoCD Sync ]
               │
               ▼
    ┌──────────────────────┐
    │  Kubernetes Cluster  │ ──► [ Prometheus & Grafana Monitoring ]
    │ (EKS via Terraform)  │ ──► [ Alertmanager & Logging ]
    └──────────────────────┘
```
